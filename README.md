# novel-tracking-app
fitbit style challenge app to track novel word count

<img width="1206" height="597" alt="IMG_1024" src="https://github.com/user-attachments/assets/dbfd69e9-3712-46c7-9641-fc5957a4339f" />


## features

* **leaderboard:** live progress bars tracking individual word counts against a 15,000-word goal
* **metrics:** real-time display showing total words written, percentage completed, and words remaining
* **daily word log:** simple submission form for competitors to select their name, log session dates, and enter word counts
* **Persistent Cloud Data:** ensures log entries survive free container restarts on streamlit cloud
* **history:** log table for all form submissions
* **custom aesthetic:** custom CSS overrides for a pink theme

## details
cloud storage - jsonBin.io via requests
frontend/hosting - streamlit
